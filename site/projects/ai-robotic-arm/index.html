AI Robotic Arm Interactive Game

A Unity UR3 simulation exploring how object labels, obstacles and game rules influence a robot’s decisions and simulated pick-and-place.

Outcome
Interactive robotics simulation prototype
01

Connecting perception and simulated movement

I adapted a Unity Robotics UR3 simulation using ROS and Docker, integrating a pretrained pose-estimation model to estimate a target object’s position and orientation for ROS-based motion planning and simulated pick-and-place execution.

02

Rules players can influence

I designed game interactions that let players influence the robot’s decisions by changing object labels and obstacle placement. Level rules specify target selection, forbidden objects and pickup order.
